Detailed Description

For proper functioning of the circular buffer, ensure the following Write can never be more than 0 to CIRCULAR_BUFFER_SIZE-1 ahead of Read Read can only ever be CIRCULAR_BUFFER_SIZE-1 up to 0 behind Write All code runs under the assumption that Write is either equal to Read or ahead of Read
