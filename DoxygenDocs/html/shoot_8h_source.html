1/* Description: Makes the robot chip or kick
2 *
3 * Instructions:
4 * 1) First the robot's needs to charge
5 * 2) when that has happened the kick or chip command can be executed
6 *
7 * Extra functions:
8 *
9 * Notes:
10 * As opposed to other functionalities, shoot uses a callback() instead of an update(). This is because shoot
11 * only needs to update when kicking is needed, while for example the velocity control needs to ran constantly. It would be
12 * very inefficient to update shoot every cycle. The timer for the callback is set internally. The time after which another
13 * callback should be made differs per shootState. While charging and kicking, updating has to be done frequently and while the
14 * robot is ready to kick, updating can be done less frequent.
15*/
